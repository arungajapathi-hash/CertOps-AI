# AZ-400: Designing and Implementing Microsoft DevOps Solutions

## Configure processes and communications

Overview
AZ-400 begins with establishing robust team workflows and communication channels. Successful candidates understand DevOps culture, collaboration workflows, and how to align processes with business requirements. This domain emphasizes planning, transparency, and rapid feedback loops.

Key concepts
- DevOps culture and collaboration
- Process automation and workflow orchestration
- Value stream mapping and continuous improvement
- Communication with stakeholders and release planning
- Change management and feedback loops

Exam tips
- Be able to describe DevOps principles in a practical scenario.
- Know the benefits of continuous feedback and fast iterations.
- Study common process automation tools used in Azure environments.

## Design and implement source control

Overview
Source control is the foundation of modern DevOps. AZ-400 tests your ability to design branching strategies, manage repositories, and secure code. GitHub, Azure Repos, and pull request workflows are central to maintaining high-quality source code.

Key concepts
- Git branching and workflow strategies
- Repository security and branch protections
- Pull request automation and code reviews
- GitHub Actions basics
- Artifact versioning and release tags

Exam tips
- Understand branch protection rules and merge strategies.
- Learn how repository policies enforce quality gates.
- Review GitHub Actions workflows for CI/CD.

## Design and implement build and release pipelines

Overview
Pipelines automate building, testing, and deploying code changes. AZ-400 covers pipeline design, YAML authoring, artifact management, and deployment strategies. You should be able to define CI/CD flows for multi-stage applications and infrastructure.

Key concepts
- Continuous integration vs continuous delivery
- YAML pipeline structure and templates
- Build agents and deployment targets
- Release strategies: blue/green, canary, rolling
- Artifact storage and staging environments

Exam tips
- Practice writing YAML for a simple build-and-release pipeline.
- Know when to use release gates and approval workflows.
- Learn differences between Azure Pipelines and GitHub Actions.

## Develop a security and compliance plan

Overview
Security and compliance are essential in DevOps. AZ-400 examines how to incorporate security checks, compliance scanning, and policy enforcement into your delivery pipeline. This includes secret management, vulnerability scanning, and security baselines.

Key concepts
- Secure pipeline design and secrets management
- Policy-as-code using Azure Policy
- Static code analysis and container scanning
- Identity and access management for deployments
- Compliance reporting and auditing

Exam tips
- Understand how to integrate security checks into CI/CD.
- Review common tools for vulnerability scanning.
- Be familiar with Azure Policy enforcement modes.

## Implement an instrumentation strategy

Overview
Instrumentation ensures that applications are observable and operations teams can act on metrics. AZ-400 evaluates knowledge of monitoring, logging, and alerting across the DevOps lifecycle. This domain focuses on telemetry, dashboards, and incident response.

Key concepts
- Logging and telemetry pipelines
- Application Insights and Azure Monitor
- Custom metrics and dashboards
- Alert rules and incident workflows
- Root cause analysis and post-mortem reviews

Exam tips
- Know how to instrument an application for health checks.
- Practice building simple dashboards for deployment metrics.
- Review how alerts map to operational runbooks.
